# Citizen Portal — Odisha Police

Official-style **Citizen Portal** for the Government of Odisha. The site gives citizens access to services, information, login/registration, a photo gallery, and the **SATHI** help assistant.

**Live demo:** [https://prabhuprasad111.github.io/CitizenPortal](https://prabhuprasad111.github.io/CitizenPortal)

---

## Overview

This project is a **React + TypeScript + Vite** rebuild of the original static Citizen Portal. The original layout, branding, and CSS are preserved while the app is structured for maintainability, API integration, and GitHub Pages deployment.

The portal includes:

- **Home** — hero, citizen services, Odisha district map, charts, FAQs, contact, and gallery preview
- **Login** — sign-in and citizen registration with bilingual (English / Odia) UI
- **Photo gallery** — filterable image gallery
- **SATHI chatbot** — FAQ topics, service status lookup, and optional AI chat
- **Accessibility** — font size, contrast, and English/Odia language toggle

---

## Tech stack

| Layer | Technology |
|-------|------------|
| Frontend | React 18, TypeScript, Vite |
| Routing | React Router (`HashRouter` for GitHub Pages) |
| UI | Bootstrap 5, Bootstrap Icons |
| Charts / maps | ECharts, ApexCharts, Leaflet |
| Gallery / motion | Swiper, AOS, GLightbox, Isotope |
| API client | Axios |
