# Project Rules

## Tech Stack
- HTML5 (multi-page static frontend)
- CSS3 (custom styles in `assets/css/main.css`)
- JavaScript (vanilla JS, no framework)
- Bootstrap 5 (layout, grid, utility classes, components)
- Bootstrap Icons (`bi` icon set)
- Swiper.js (hero slider/carousel interactions)
- ApexCharts (hero analytics/metrics charts)

## Coding Standards
- Use services for API calls
- Use shared components where possible
- Follow existing table design patterns
- Maintain consistency with previous report components

## Important Features
- Crime Dashboard
- FIR Reports
- District-based filtering
- PDF export functionality

## Notes for AI
- Do NOT redesign UI unless asked
- Extend existing components instead of creating new ones
- Reuse existing services like HttpCallService, DataSharingService
